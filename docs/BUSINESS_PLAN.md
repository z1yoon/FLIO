# FLIO 사업계획서
**AI 기반 진지한 만남 데이팅 플랫폼**

작성일: 2025년 12월
버전: v1.0 (기록용)

---

## 📌 핵심 요약

**FLIO**는 결혼정보회사의 깊이와 데이팅 앱의 편리함을 결합한 AI 매칭 플랫폼입니다.

- **타겟:** 진지한 연애/결혼을 원하는 25-40세 (1,160K명) + 장애인 시장 (120K명)
- **차별화:** AI와의 솔직한 대화로 정확한 프로필 작성(음성/텍스트) + 파고드는 적응형 질문으로 진짜 원하는 조건 파악 + 설명 가능한 매칭
- **가격:** 연 ₩300,000 (결혼정보회사의 1/10)
- **목표:** 1년 내 60,000 사용자, 12% 유료 전환, ₩30억 매출

## 🎯 문제점

### 현재 시장의 문제

1. **결혼정보회사** (듀오, 가연, 선우)
   - ❌ 너무 비쌈: 연 ₩2,700,000
   - ❌ 불편함: 강남 사무실 방문 필수
   - ❌ 느림: 매칭까지 수 주 소요
   - ❌ 불투명: 왜 매칭되는지 설명 없음
   - ❌ **솔직하지 못함**: 매니저 앞에서 체면 차리느라 진짜 원하는 조건 숨김
     - 예: "경제력 중요해요" ≠ 진심 "연봉 1억 이상"

2. **데이팅 앱** (Tinder, Amanda, GLAM)
   - ❌ 너무 가벼움: 캐주얼 만남 중심
   - ❌ 얕음: 사진 + 3줄 소개뿐
   - ❌ 피로감: 끝없는 스와이프
   - ❌ 낮은 성공률: 3-8%

3. **모든 서비스**
   - ❌ 접근성 부족: 장애인 사용 불가
   - ❌ 시간 소모: 프로필 작성에 1-2시간

**시장 규모:** 1,280,000명 × ₩300,000 = **₩3,840억 시장**

## 💡 솔루션: FLIO

### 제품 개요

**모바일 기반 AI 데이팅 플랫폼 - 음성으로 빠르고, AI로 깊게, 모두가 사용 가능**

### 핵심 기능

#### 1. 적응형 AI 질문 엔진 🧠

**문제 1:** 획일적 프로필은 호환성 파악 불가
**문제 2:** 매니저 앞에서는 체면 때문에 솔직하지 못함
**해결:** AI와의 익명 대화로 진짜 원하는 것을 파악하는 30-50개 적응형 질문

```
AI 아바타: "결혼 계획이 있으신가요?"
사용자: "음... 생각 중이에요"
→ AI 감지: 답변이 애매함
AI: "구체적으로 언제쯤 생각하시나요?"
사용자: "2년 이내요"
→ AI: "알겠습니다! 다음 질문 드릴게요"
```

**솔직한 답변 유도 예시:**
```
AI: "상대방의 경제력이 얼마나 중요한가요?"
사용자: "음... 중요해요"
→ AI 감지: 구체적이지 않음
AI: "구체적으로 어느 정도 연봉을 원하시나요?"
사용자: "최소 8천만원 이상이요"
→ AI: "솔직하게 말씀해주셔서 감사합니다. 정확한 매칭에 도움이 됩니다!"

[매니저와 대화 시]
매니저: "경제력 중요하세요?"
사용자: "어... 그냥 경제적으로 안정적이면 돼요..." (체면 차리기)
→ 결과: 부정확한 매칭
```

**핵심 차별점:**
- 답변 명확 → 다음 주제로
- 답변 애매 → 파고드는 질문으로 진심 파악
- AI라서 판단받는 느낌 없음 → 솔직한 답변 가능
- 사용자 피드백으로 질문 순서 최적화

#### 2. 편리한 입력 옵션 (텍스트/음성) ⌨️🎤

**문제:** 30+ 답변 타이핑은 피곤함 (40-60분 소요)
**해결:** 음성 입력 옵션 제공 (15-25분 소요)

```
┌─────────────────────────────┐
│ 질문: 결혼 계획이 있으신가요?  │
│                              │
│ [⌨️ 입력하기]  [🎤 말하기]  │
│  (기본 방식)    (편의 기능)   │
└─────────────────────────────┘
```

**사용자 선택권:**
- 기본: 텍스트 입력 (익숙함)
- 옵션: 음성 입력 (빠름)
- 언제든 전환 가능

**효과:**
- 음성 사용 시 완료율 76% (vs 텍스트 28%)
- 프로필 작성 시간 3배 단축
- 출퇴근 중 이어폰으로 가능

**부수 효과:**
- 장애인도 사용 가능 (정부 보조금 자격)

#### 3. 설명 가능한 AI 매칭 📊

**문제:** 사용자가 왜 매칭되는지 모름
**해결:** AI가 한국어로 이유 설명

```
┌──────────────────────────────────────┐
│  김민준, 32세                   89%  │
│  ┌────────────────────────────────┐  │
│  │ 매칭 이유:                      │  │
│  │ ✅ 결혼·가족관이 매우 비슷해요  │  │
│  │    (2년 이내 결혼, 자녀 2명 희망)│  │
│  │ ✅ 재정 관리 방식 일치          │  │
│  │    (공동 계좌 선호)             │  │
│  │ ✅ 주말 활동 취향 같음          │  │
│  │    (등산, 독서)                 │  │
│  │ ⚠️ 종교 차이 있음               │  │
│  │    (대화 권장)                  │  │
│  └────────────────────────────────┘  │
│  [프로필 보기]  [메시지 보내기]      │
└──────────────────────────────────────┘
```

#### 4. 다단계 인증 시스템 ✅

**자동화된 AI 인증 (사람 없이 운영 가능)**

**1단계: 기본 (무료, 필수)**
- PASS/NICE 휴대폰 인증 (실명, 나이)
- AI 얼굴 생체 인식 (사진 vs 실제 구분)
- AI 사진 분석 (편집/가짜 감지)
- 행동 패턴 분석 (봇 감지)

**2단계: 인증 배지 (₩10,000)**
- 학력 인증 (졸업장 OCR)
- 재직 인증 (회사 이메일/급여명세서)
- 소득 구간 (정확한 금액 아님 - "₩50-70M" 범위)

**3단계: 프리미엄 인증 (₩30,000)**
- 신원 조회 (범죄 기록)
- 자산 인증 (선택)

**비용:** ₩250/사용자 (vs 결혼정보회사 수동 검증)

#### 5. 종단간 암호화 메시징 🔐

- Signal Protocol (WhatsApp과 동일)
- 메시지 기기 암호화, 서버도 읽기 불가
- 개인정보 보호

#### 6. 보편적 접근성 ♿

**모든 사람에게 더 나은 UX:**
- 음성 탐색 (STT/TTS)
- 큰 글씨 모드
- 고대비 모드
- 키보드 탐색
- 햅틱 피드백
